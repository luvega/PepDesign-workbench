# AI 辅助提示词

下面的提示词可用于普通 AI。若已在 Codex 安装 Baker skill，可保留 `$baker-protein-design`；没有安装也能按这些问题手工完成。给 AI 提供实际材料，并核对它是否声称检查了无法访问的文件。

## 1. 从问题选择方法

```text
Use $baker-protein-design 帮我完善下面的研究任务卡。
先区分设计对象和结合对象，根据 PepDesign-workbench 的固定方法登记与教学案例，
推荐适用的 1—2 种方法并说明理由；不适用时可以不推荐。
把未知输入保留为未知，不虚构表位、序列、结构或执行参数。
Workbench 方法沿其原生接口准备，本任务卡不要交给 Baker CLI 生成其他后端命令。
我的问题与已有材料：在此粘贴。
```

使用后检查：AI 是否分清了“设计结合蛋白的肽”和“设计结合肽靶标的蛋白”？是否为单体环肽凭空添加了受体？

## 2. 根据目标修改配置

```text
所选 method ID、commit、案例和原生接口说明：在此给出。
核对目标、必须条件、偏好和排除条件，逐项说明：
对应哪个原生字段或操作，是强制指定、引导生成还是尚未设置，输出后怎样检查。
尚未设置时，说明是方法不支持，还是本次未采用。
分清人工记录和程序输入；seed、checkpoint、cyclic 等选项须以该接口实际支持为准。
只做静态核查，不安装、下载资产或启动模型。
我的任务卡、输入来源与配置：在此粘贴。
```

使用后检查：链、编号、长度上限、参考配体用途和环境路径是否有依据？零值和排除条件是否保留？

## 3. 审阅结果

```text
我提供的结果来源：上游报告/合成教学记录/本项目实跑，具体如下。
先说明你能检查哪些材料，再分别报告运行状态、原生过滤结果、产物类型和研究判断。
记录总尝试数和失败数，保留模型分歧、原生/重设计序列及输入准备的差异。
根据实际材料检查长度、环闭合、手性、几何或界面；缺少坐标时标未检查。
可采用我确认的来源。说明证据是否适用，有何对照或独立复核，结果是否稳定，有无冲突。
不同含义的分数不求平均；优化进步不等于独立验证，预测不等于实测结合。
材料与对应原生指标定义：在此粘贴。
```

## 4. 决定下一步

```text
根据任务卡和审阅记录，写清当前决定、支持证据、冲突或缺失信息，以及下一步和理由。
可以推荐候选或保留少量候选探索，也可以没有候选。
下一步可以继续、修复、换方法或停止，要说明它解决什么问题。
是否需要外部金标准或湿实验，按本项目要作出的结论决定。
保留旧轮次，说明哪些改动会影响新旧结果的比较。
现有记录：在此粘贴。
```

## 使用后的自我解释

合上 AI 回答，用自己的话说明方法需要什么输入、能得到什么，以及目前还不知道什么。解释不清时，重新读输入和原生字段说明。

这些提示词只辅助讨论。Workbench 方法尚未因此接入 Baker 执行器；CLI 误路由修复和运行接入留待后续。
