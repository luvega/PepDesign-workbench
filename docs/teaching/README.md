# 多肽与蛋白 binder 设计：本科生教学样版

这套教材面向初次学习计算设计的本科生。你将练习提出问题、准备输入、修改配置、审阅结果，再决定是否继续。十种方法各有一份样版，按自己的项目选择 **1—2 种**学习即可。

**版本：2026-10-21。** 方法版本按[方法登记](../../registry/methods.json)中的 commit 固定，示例取自相应上游。

目前完成的是教材编写，尚未在本项目运行模型。服务器、环境和模型文件仍待检查。每例完整讲解问题、配置和判断过程；运行步骤留待环境就绪后执行，练习记录另行标注来源。

## 从自己的问题出发

| 已有输入或研究问题 | 先读哪个样版 | 读结果时注意什么 |
|---|---|---|
| 只有受体序列，先提出候选肽序列 | [01 PepMLM](cases/pepmlm.md) | 只有序列，尚无复合物坐标，不能检查三维手性 |
| 有受体结构及候选表位，想设计结合肽 | [02 DiffPepBuilder](cases/diffpepbuilder.md)、[03 PepGLAD](cases/pepglad.md) | 两者的位点写法、预处理和长度范围不同 |
| 想学习 D 肽的镜像设计 | [04 Mirror-Peptidizer](cases/mirror-peptidizer.md)、[05 PepMirror](cases/pepmirror.md) | 最终肽和受体的手性都要检查 |
| 有单体环肽骨架，想设计相容序列 | [06 AfCycDesign](cases/afcycdesign.md) | 本例只研究单体结构，没有受体结合结果 |
| 想准备 D/L 复合物并进行能量搜索 | [07 DexDesign](cases/dexdesign.md) | 先准备有效输入，再确认构象库及 CPU、内存需求 |
| 想先生成新 binder 骨架，再设计序列 | [08 RFdiffusion＋ProteinMPNN](cases/rfdiffusion-proteinmpnn.md) | 骨架、序列和全原子复合物是不同产物 |
| 想学习蛋白 binder 的设计与原生过滤 | [09 BindCraft](cases/bindcraft.md) | 接受数量、尝试数量和实验成功不同 |
| 想针对受体设计环肽 | [10 BindCraft2](cases/bindcraft2.md) | 用原生 modality 选环肽路线，输出后仍要检查闭环 |

按这张表选择学习入口，表中顺序不表示性能高低。特别要分清“设计结合蛋白的肽”和“设计结合肽/IDR 靶标的蛋白 binder”：两者的设计对象相反，仅看方法名中的 peptide 容易选错。

## 每个样版怎样学习

1. 读完整示范，弄清每步为什么这样做，并回答“自我解释”问题。
2. 做三道补全练习。先决定下一步，再练习审阅结果，最后自行修改配置并完成后续判断。教师可按掌握情况调整进度。
3. 做两项独立任务，其中一项用于自己的项目。用[研究任务卡](common/research-task-card.md)写清目标，用[迁移与提交模板](common/project-transfer.md)解释修改和判断。
4. 环境就绪后，按[方法文档](../methods/README.md)运行。在仓库外保存配置和产物，记录实际运行状态。

开始前，应能辨认 FASTA、PDB/mmCIF、链和残基编号，分清序列、骨架与全原子结构，并能修改路径和简单配置。首次环境部署和模型文件准备由教师组织。

## 先看记录来自哪里

| 材料标记 | 含义 | 可以做什么 |
|---|---|---|
| 上游公开示例 | 已核对的结构、测试记录或原生配置 | 学习输入和参数；不能写成本服务器的复现结果 |
| 合成教学记录 | 为练习人工编写的摘要、计数或异常 | 练习审阅和判断；不能作为真实候选的证据 |
| 本项目实跑结果 | 后续实际运行所得，目前尚无 | 记录输入、版本、运行状态及原始产物位置 |

案例中的候选 A/B 和数值按各例标注使用，没有对应的真实生成序列、结构或测量。未做的检查写“未检查”。如果没有值得推荐的候选，可以说明为什么先修复、小规模探索或停止。

## 可以用 AI，但要能独立解释

[AI 辅助提示词](common/ai-prompts.md)可帮助你明确目标、核对字段和审阅结果。Baker skill 用于研究判断，Workbench 提供各方法的原生操作说明。

研究任务卡不能直接交给 Baker CLI。当前 CLI 仍可能把部分外部方法误转到其他后端，这项修复留待后续；编写教材也没有为十种方法增加执行适配器。

采用 AI 建议前，要对照固定来源和自己的输入核查。写下环化或 D 肽要求后，还要确认方法是否支持、输出是否满足。
