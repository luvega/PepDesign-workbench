# 教师指南：设计、审阅与下一步判断

这套教材供初次学习计算设计的本科生使用。学生按项目选择 1—2 种方法，首次环境准备由教师组织。方法、配置和来源以[方法登记](../../registry/methods.json)为准。任务卡用于说明研究计划，不能直接启动计算。

**版本：2026-10-21，教材编写阶段。** 本项目尚未运行模型、部署服务器或验证课堂效果。原生调用供后续操作参考，练习摘要已注明来源。合成记录不能填入真实 run record。

## 组织学习与反馈

1. 开始前，让学生指出设计对象、受体、参考 ligand 和新产物，并在文件中找到相应链和残基。
2. 阅读完整示范后，先回答“自我解释”问题，再做补全练习。
3. 练习 1 已给结果审阅，只让学生决定下一步；练习 2 由学生审阅并决定；练习 3 再加入配置修改。输入来源和对应关系的说明保留更久。
4. 科研判断未必比配置简单。前两题给定记录，是为了减少同时处理的信息；减少提示时仍须提供必要证据。学生有充分理由时，可以与参考答案作出不同决定。
5. 能独立解释练习 2 的学生可提前进入个人项目；仍混淆编号或性质时，换一组记录再练。能否解释比能否照抄命令更重要。

每例有两项独立任务：先换一个公开对象或输入情景，再用于个人课题。它们没有唯一序列、靶标或最优方法，按下面的标准评价。

## 共用提交与评价

学生提交[任务卡](common/research-task-card.md)、修改后的原生配置或 API 输入说明、运行记录，以及[迁移审阅与决定](common/project-transfer.md)。尚未运行时注明未执行。哈希和日志只需链接到原生记录，不必重复抄写。

| 维度 | 达成的表现 | 需要修改的典型表现 |
|---|---|---|
| 问题与方法 | 分清对象、目标与方法支持的条件 | 因方法名称相似而错选；凭空造受体 |
| 输入与修改 | 能找到所用构建体、编号、字段来源及修改理由 | 只换蛋白名；复制原例热点或不存在的参数 |
| 产物审阅 | 按实际产物检查，记录失败和未检查项 | 序列当三维结构；原生接受当实验结合 |
| 科学判断 | 解释证据是否适用、是否稳定，有无支持或冲突 | 把分数相加成总可信度，按模型票数下结论 |
| 迁移与后续 | 新任务有实质改动，下一步解决明确问题 | 无理由扩大批量，或把零推荐当没完成作业 |

可用“达成／需补充／需修复”反馈，不必给科学可信度打总分。没有外部 benchmark 或湿实验不自动判为不合格；若声称实测亲和力或功能，就应提供相应测量。

## pepmlm

[学生样版](cases/pepmlm.md)

- **示范要点：**6VME 使用 TSG101 构建体片段和参考链，不能换成全长蛋白仍算同一输入。原 CSV 的结构指标不是本次生成所得。合成批次有 3 条原始记录，2 条长度合格，去重复后剩 1 条合格序列。
- **练习 1：**可保留 A 做结构评估，合并 C，检查 B 的长度问题；也可以复核输入和序列后决定暂时停止。B 的 pseudo-perplexity 较低，仍不能说明实测结合。
- **练习 2：**先查 D 的原始生成和解析，不能擅自替换 `X` 后比较。E 可继续评估，但 9.0 不是 KD，没有坐标也无法判断三维手性。
- **练习 3：**分别请求 12 和 15 aa，其他采样设置保持一致，或解释为何不同。分别统计原始记录、长度和字符合格记录、去重复后的候选。不同长度的模型分数未必能直接比较生物学质量；没有数据时只交方案。
- **独立任务评价：**能找到实际构建体序列及来源；需求依赖位点或立体构型时，能解释为什么组合或改用其他方法。不能把低分或输出条数直接当作效果。

## diffpepbuilder

[学生样版](cases/diffpepbuilder.md)

- **示范要点：**原始 6SF1 中 ALK1 为 A，上游工作文件 `alk1.pdb` 中为 B。预处理会改写工作输入，须保存原件并核对前后对应。
- **练习 1：**在新轮次修复 A 的热点和链对应，保留 B 做有限探索。之后的比较要使用可核对的相同目标和准备条件；错位点上的高分不能用来选优。
- **练习 2：**全局 RMSD 很低时，局部仍可能移动很大。要核对热点残基、局部原子和接触，以及准备前后关系。没有坐标就写待检查，不能用一个通用位移阈值直接判断不结合。
- **练习 3：**两份配置分别只填 hotspot、只填 motif。核对程序实际采用的来源，并记录其他参数及输出是否满足要求。混填三类条件不表示三者都被独立采用。
- **独立任务评价：**位点对应实际文件，副本处理记录清楚。缺少位点来源时，应保留未知并提出定位办法，不能照抄 B40。

## pepglad

[学生样版](cases/pepglad.md)

- **示范要点：**1SSC 是半合成 RNase A 片段体系。A 是本例 target，B 是参考链，换受体后要重新确定角色。`length_max` 不包含上限。
- **练习 1：**可先对照 A 生成和 relax 前后的原子、残基，查手性异常；也可对 B 比较不同但可比的输入准备方式。有全原子文件不代表全部性质通过。
- **练习 2：**核对序列摘要、原始 PDB、残基和原子对应，以及导出、修复记录。先分清是缺坐标、计数错误还是序列错误。保留“摘要12/PDB11”的冲突，暂不确认完整 12 aa 几何。
- **练习 3：**固定 12 aa 用 `--length_min 12 --length_max 13`。口袋按实际链、author residue number 和插入码填写。入口没有 `--seed` 或 `--ckpt`，默认模型文件路径也要核查。
- **独立任务评价：**能说明参考 ligand 的用途；没有参考链时，提出其他有依据的口袋来源。能区分有原子文件、化学合理和功能测量三个问题。

## mirror-peptidizer

[学生样版](cases/mirror-peptidizer.md)

- **示范要点：**4LWV 的输入是 humanized Xenopus MDM2，不能直接外推到普通人源野生型。Tier-1 初始设计与 BO 分开记录，序列字母不能表达坐标手性。
- **练习 1：**先把 B 的最终文件与原始输入、反射及修复记录对应起来，再选结构检查或输入准备比较。人源适用性、稳定性、耐蛋白酶等结论各需证据，但不要求本轮完成所有实验。
- **练习 2：**unknown 可能来自缺原子或无法对应残基，不能写成已确认变 L。对比修复前后的坐标、残基和工具处理，保留异常；只限制受影响的分数，不连带丢弃其他可解释记录。
- **练习 3：**设置新 L 受体、长度、pose 数、每 pose 序列数、输出和 BO 0，追踪最终受体 L、肽 D。模型和环境按实际准备状态填写，不写入凭据。
- **独立任务评价：**分别判断坐标手性、几何、结合及其他功能，能说明自己的构建体和反射过程。

## pepmirror

[学生样版](cases/pepmirror.md)

- **示范要点：**7MDP A 为 KRAS，HI 表示参考 Fab 链集合，不能当作一条已知短肽。Chothia 工作编号与原始 PDB 编号要分别核对。
- **练习 1：**保存错配配置和原始记录，在新轮次使用匹配的 checkpoint 与特征。错配时的好分数不能说明更优；A 尚未做的坐标检查仍写未检查。
- **练习 2：**候选落在参考区域，只能说明有限的位置一致性。缺少整个复合物镜像返回后的文件，尚不能确认 L 受体＋D 肽；应补回完整过程并检查两方最终手性。
- **练习 3：**参考链改为 B，单复合物列表按原生格式填写。固定 13 aa 用 `size_min: 13,size_max: 14`，checkpoint 与 axial 特征须匹配。生成与后续修复分别记录。
- **独立任务评价：**只有受体时，能提出可行且有依据的口袋来源，并说明缺少哪些准备。改变拓扑或手性时，能给出对应操作及输出检查。

## afcycdesign

[学生样版](cases/afcycdesign.md)

- **示范要点：**PLP-22 是 7M28 的名称，输入实际长 7 aa。本例 fixbb 没有受体，helper 取自固定 notebook，教材没有提供统一 CLI。
- **练习 1：**可先查 A 的导出和头尾原子，也可对 B 做可比构象检查。B 可保留研究单体几何，但还不能确认合成、结合或平衡构象。
- **练习 2：**Cα 邻近不足以判断头尾连接和完整化学。应检查实际环化原子、端基、封闭基团、原子完整性和局部几何；现有规则只看 Cα，其余应写未检查。
- **练习 3：**使用实际 9 aa 骨架，选择 fixbb、对应链和 model，以及同一来源的 cyclic offset，按输入长度审阅。无需添加 target 或 `binder_len`；改做 binder 时要另行接入并验证。
- **独立任务评价：**分清固定骨架设计、无靶标从头生成和针对受体设计，能解释环化类型及自己准备检查什么。

## dexdesign

[学生样版](cases/dexdesign.md)

- **示范要点：**8GAJ 为 L/L 结构，prepared D/L 仍需构建。链配对按结构和生物学信息确认，不能按字母相邻猜。输入有效、进程结束、搜索收敛和化学质量要分别检查。
- **练习 1：**先查 A 的输入来源和搜索截断问题，不能按低能量选优。B 的结论限于其声明的小搜索空间。没有有效 D/L 输入时，应先准备输入。
- **练习 2：**记录“进程成功退出，搜索未收敛”，保留数值范围和状态。是否继续取决于研究问题和预算，不能只看退出码。
- **练习 3：**在教师核实的输入上，限定可变位点、允许构象、D 库和化学关系；线程、内存及时间待资源确认。修改文件内设置和生成作业，不添加 `--weights`。不同搜索空间的结果不能直接排名。
- **独立任务评价：**分清原始 L/L 结构事实和新增 D/L 假设，给出 prepared 输入来源及手性、连接检查。能说明自己的问题无需此方法，也可作为合理答案。

## rfdiffusion-proteinmpnn

[学生样版](cases/rfdiffusion-proteinmpnn.md)

- **示范要点：**两个方法用各自环境，先生成骨架，再设计序列。RF 可能重分配输出链，`/0` 后的空格不能删。官方 PPI 输入没有已核对的 PDB 编号时，不自行补写。
- **练习 1：**X 在新轮次改正设计链，原错误序列不参与选择。Y 保留每条序列与骨架的对应关系，再安排建模和检查。MPNN 好分数不能证明结合。
- **练习 2：**序列相容性和复合物 pose 回答不同问题，同一骨架的 3 条序列不能算 3 票。对照输入、生成条件、模型和局部位姿，保留冲突，再选能区分原因的小比较。
- **练习 3：**按给定区间填写 target contig、热点和两种长度；看到实际输出后再填设计链。分别统计骨架、每骨架序列、FASTA 中原始和生成项。没有输出时不能猜 A/B。
- **独立任务评价：**能分清固定位置和设计位置，找到各步产物。短肽或环肽需求要重新判断方法是否适用，不能只改长度。

## bindcraft

[学生样版](cases/bindcraft.md)

- **示范要点：**basic、advanced、filters 各有用途。请求接受 1 个不表示尝试 1 次。合成案例有 8 次尝试、3 次早期失败、5 条保存轨迹、1 个接受者；1/8 不是实测命中率。
- **练习 1：**可先分析早期失败，也可核对接受者的目标和准备条件后，决定是否少量跟进。最终表的一行不足以支持扩大采样。
- **练习 2：**兼容对照也被拒，应先查对应关系、准备过程和规则是否适用，保留 0/6 及原规则。修改规则时另存新协议和理由；参与调规则的对照用于校准，不能再算独立验证。六个候选也不能记为实测不结合。
- **练习 3：**按新任务修改 target、链、热点、长度和输出；完整 advanced/filter 取自固定上游。预算要覆盖总尝试、早期失败及运行时间，不能只看已保存轨迹上限。原生 CLI 没有 `--seed`。
- **独立任务评价：**预设适合蛋白或短肽任务，总尝试数记录清楚。跨方法比较时，匹配长度、预算、准备和过滤，或解释其差异。

## bindcraft2

[学生样版](cases/bindcraft2.md)

- **示范要点：**BindCraft2 有独立 campaign、环境和来源，hPDL1 热点只对应该工作输入。设置 cyclic modality 后仍需原子检查；默认 closure filter 没有设置有限接受阈值。
- **练习 1：**为 A 补头尾原子和局部几何检查。B 保留拒绝原因，再决定修复或探索。A 被接受不能证明闭环，B 被拒也不能证明实测不结合。
- **练习 2：**保存两轮原始配置、规则、轨迹和接受数。筛选规则已变，0/1 到 1/1 不能直接说明同一尺度下成功率提高，更不是独立验证。应说明改动了什么选择规则。
- **练习 3：**用 `peptide` 和 `cyclic_peptide` 分别建立 campaign。受控比较要匹配长度和计算投入，或解释差异。探索可用不同预算，但不能因此直接宣称方法更优。闭环只在环肽分支检查，L/D 和其他几何仍按实际产物核对。
- **独立任务评价：**能分清有意开放位点和资料未知，也能分清生成条件与输出性质。保留原生、重设计、线性肽和环肽的不同记录。

## 之后怎样补真实运行

先查清 GPU 型号和显存、CPU、内存、系统、各方法环境、模型文件及可用计算时间，再为每种方法补入实际配置、输入和产物位置、运行状态。建议先安排 PepMLM、PepGLAD，再安排 DiffPepBuilder、RF＋MPNN、BindCraft、BindCraft2，最后处理镜像、Notebook 和 D/L 搜索所需的额外准备。这个顺序按准备工作安排，不表示性能排名。

文档检查通过后，实际运行仍待验收。首次运行可以零接受，但要能说明输入、运行范围、拒绝原因和未检查内容。实际运行记录不能用合成摘要代替；教师校准记录和学生练习也不能合并成模型 benchmark。

## 原则来源与维护

练习采用 worked-example fading：先看完整例子，再逐步减少配置和检查提示。科研判断允许多种有依据的答案。方法细节按固定上游核对，练习中的阈值和规模只适用于该例。

研究判断参考 [Baker 决策指南](https://github.com/luvega/design_dock_skills/blob/6043bb4b2c3665a14b4a1276708f5a41a758a0e4/skills/baker-protein-design/references/binder-campaign-decisions.md)和 [EGFR 审阅演练](https://github.com/luvega/design_dock_skills/blob/6043bb4b2c3665a14b4a1276708f5a41a758a0e4/docs/research/egfr-updated-skill-walkthrough-2026-10-15.md)。可采用已确认可靠的来源，同时说明结果是计算还是实测、验证是否适用，以及下一步理由。本教材不统一要求外部金标准、模型一致或重新设计序列。

维护时核对十个案例、教师答案和原生接口是否一致，重点检查人工 JSON 的用途、长度上限、链和残基对应、镜像返回、环闭合及各阶段计数。记录学生常见误解，供后续修改教材。
