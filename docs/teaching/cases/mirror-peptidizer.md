# 04｜Mirror-Peptidizer：检查镜像设计后的受体与 D 肽

**method ID：**`mirror-peptidizer`。**任务：**为 L 受体设计 D 肽。**状态：**教材已编写，尚未执行设计或 BO；Chroma/MPNN 模型文件、环境和手性检查待验收。

## 阶段一：完整示范

### 本例要解决什么问题

输入为上游 `data/4LWV.pdb`。来源结构 **4LWV** 是 humanized Xenopus MDM2 与 RO5545353 的复合物，并非普通人源野生型 MDM2。RO5545353 是小分子参照，不能当作已知 D 肽结合物。

本例设计 11 aa D 肽，先检查镜像流程结束后是否得到 L 受体和 D 肽候选。能否用于人源靶标、是否稳定、能否结合，需分别判断。

| 步骤 | 本例怎样做 | 为什么 |
|---|---|---|
| 1 目标 | 用该输入做一次 Tier-1 初始设计 | 先弄清骨架生成和序列设计，再考虑后续优化 |
| 2 输入确认 | 使用固定版提供的 4LWV 文件；登记实际链、构建体及保留组分 | 数据库原件和方法输入未必可直接互换 |
| 3 设置参数 | 长度 11、1 pose、每 pose 1 sequence、BO 0 轮 | 参数规定长度和规模，最终手性要看坐标 |
| 4 原生运行 | 反射受体，生成 L 骨架并设计序列，再返回 D 候选 | 中间镜像文件不能直接作为最终复合物 |
| 5 审阅结果 | 检查最终受体与肽的手性、原子对应及反射和修复记录 | 肽序列字母不能说明三维手性，两方坐标都要看 |
| 6 决定下一步 | 输入和手性正确时再探索，错误先修复 | D 构型本身不能证明结合或耐受性 |

### 原生步骤与修改指南

按[原生方法说明](../../methods/mirror-peptidizer.md)准备获授权的模型和依赖，凭据留在教材和任务卡之外。本阶段尚未安装或下载。环境就绪后，从固定版本源码目录调用；输出路径仍待配置：

```bash
python run_design.py \
  --receptor data/4LWV.pdb \
  --output /path/to/course/mirror-initial \
  --len_binder 11 --num_poses 1 --num_seqs_per_pose 1 \
  --temperature 0.1 --gpu 0 --bo_rounds 0
```

本例比官方演示减少了 pose 和序列数，并关闭 BO，实际耗时尚未测量。[CLI 参数记录](../../../configs/mirror-peptidizer/cli-inputs.template.json)供人工填写，不能作为 `run_design.py` 配置文件。

| 分类 | 字段／操作 | 自己项目怎样改 |
|---|---|---|
| 必须修改 | `--receptor`、`--output` | 实际 L 受体及新轮次目录，保留原始结构 |
| 可以调整 | `--len_binder`、`--num_poses`、`--num_seqs_per_pose`、`--temperature` | 按问题和预算选择，记录每条序列对应哪个骨架 |
| 另行决定 | `--bo_rounds` 及 BO 相关参数 | 作为后续独立阶段记录，不把优化增益当独立验证 |
| 不能照抄 | 4LWV 的构建体身份和所有中间文件角色 | 不能把所有“mirror”文件都当最终 D 肽输出 |

分别保存初始输入、反射后受体、生成骨架、各条序列，以及最终返回和修复后的结构。按实际残基坐标判断 `L`、`D` 或 `mixed`，大写氨基酸字母不能代替这一检查。坐标缺失时写 unknown；Gly 无手性与缺原子导致未知是两回事。

输出不符合本例 D 要求时应查明原因。其他任务可能允许 mixed，不能把它一概判为失败。

### 合成教学记录：怎样审阅

人工设定两份摘要：A 的最终受体仍是 D 镜像，候选为 L；B 的最终受体为 L，候选的每个非 Gly 残基均符合本例 D 要求，但没有实测结合。练习没有真实坐标或手性检测结果。

A 可能仍是中间文件，也可能在返回步骤出错。先定位并修复；它的分数不能支持候选对实际 L 受体的判断。

B 可继续做结构检查、比较不同输入准备方式，或研究功能。但目前不能声称它结合人源 MDM2、耐蛋白酶或具有免疫优势。后续若用同一评分优化 B，分数进步只说明该评分下的优化表现，是否增加独立证据还需另作解释。

**自我解释：**为什么不能只检查肽链？为什么 MPNN 的大写字母不表达 D？为什么从这个 4LWV 起点不能直接推断普通人源 MDM2 的结果？
