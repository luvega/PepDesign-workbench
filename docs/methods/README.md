# 方法目录

各方法独立配置。源码参考用于核对接口；安装、模型资产与运行由用户在方法自己的环境中完成。

| 方法 | 接口类型 | 原生说明 |
| :--- | :--- | :--- |
| PepMLM | Python 函数与模型加载 | [PepMLM](pepmlm.md) |
| DiffPepBuilder | 受体预处理 + Hydra CLI | [DiffPepBuilder](diffpepbuilder.md) |
| PepGLAD | Python module CLI | [PepGLAD](pepglad.md) |
| Mirror-Peptidizer | Python CLI | [Mirror-Peptidizer](mirror-peptidizer.md) |
| PepMirror | YAML + Python module CLI | [PepMirror](pepmirror.md) |
| AfCycDesign / ColabDesign | notebook / Python API | [AfCycDesign](afcycdesign.md) |
| DexDesign / OSPREY3 | Python / JVM 与原生搜索脚本 | [DexDesign](dexdesign.md) |
| RFdiffusion + ProteinMPNN | 两阶段原生 CLI | [RFdiffusion + ProteinMPNN](rfdiffusion-proteinmpnn.md) |
| BindCraft | basic / advanced / filter JSON + CLI | [BindCraft](bindcraft.md) |
| BindCraft2 | 独立 campaign JSON + CLI | [BindCraft2](bindcraft2.md) |
