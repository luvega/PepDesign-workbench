# 输入与输出

## 输入准备

序列输入使用用户自备 FASTA，保留原始文件、序列来源和截取说明。序列模型的氨基酸字母并不直接定义三维手性。

结构输入由用户提供。核对受体链、残基编号、缺失区域、非标准残基、二硫键、糖链和配体。不同原生解析器可能删除或改写这些对象，应在解析前后检查，并明确哪些组分进入模型。

结合区域需按方法格式描述：hotspot、口袋、参考 ligand、contig 或显式搜索空间不是可互换字段。参考 ligand 也不能仅改名就当作模型要求的有效口袋定义。

模板中的 `receptor.pdb`、`complex.pdb`、`receptor.fasta` 和路径变量都是用户输入占位。仓库不提供分子输入文件。

## 产物层级

| 层级 | 应保留的原始产物 | 可检查的信息 |
| :--- | :--- | :--- |
| 序列 | 原生序列文件与采样配置 | 长度、字母表、重复、输入关联 |
| 骨架 | 原生骨架坐标与链定义 | 链连通性、骨架几何、拓扑与空间关系 |
| 全原子复合物 | 原生坐标、序列映射和原生过滤记录 | 原子完整性、逐残基手性、局部几何、碰撞与界面 |
| 能量搜索 | 搜索空间、原生状态、构象 ensemble 和数值记录 | 搜索是否完成、数值是否有效、输出构象与序列是否对应 |

不将缺少侧链的骨架报告为全原子结构。原生 confidence、能量和序列兼容性各有含义，不作为通用结合亲和力。

## 记录建议

[任务记录模板](../configs/run-record.template.json)是人工记录格式，不是设计程序的输入。填写方法 ID、源码参考、输入和权重摘要、环境、原生命令、输出目录与完成状态。原始输出保留在外部任务目录；衍生修复应另存文件并记录操作。
