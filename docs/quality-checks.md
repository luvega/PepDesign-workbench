# 产物检查

检查内容随产物层级和设计意图变化。先确认原生任务是否完成，再判断候选是否满足当前任务的质量要求。

## 序列与坐标对应

确认序列长度、字符、链映射和残基编号。未知字符或缺失侧链需要明确记录，不能通过改写序列掩盖。仅有序列时，手性和三维结构记为未确定。

## 手性与拓扑

逐残基记录 L、D、mixed、achiral 或 unknown，区分 Gly 的无手性与坐标缺失导致的未知手性。D 肽和 mixed 肽按其实际结构检查，不因方法名称或混合本身判为失败。

镜像路线同时检查受体和多肽，确认反射、结构修复或最小化后的最终坐标。环肽检查头尾闭合和局部几何；模型中的 cyclic offset 不能替代化学闭环检查。

## 几何与空间关系

检查骨架连通性、键长、末端几何和碰撞范围。局部异常应定位到具体原子与残基并记录；广泛严重碰撞、断裂或输入映射丢失应先排查。任何修复都保留原始产物，分别检查修复前后。

使用阈值时，记录阈值、所需原子范围和适用任务。不同方法的原生过滤器各自保留，不把它们的通过与拒绝直接等同为共同质量尺度。

## 输出记录

分别保存运行状态、原生过滤状态、产物层级、手性、几何异常和待处理项。候选是否继续用于探索，应结合设计意图与异常程度决定；计算 confidence 或能量输出不能证明合成、结合或功能。
